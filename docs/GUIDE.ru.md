# Как пользоваться Phaint

## Установка на Mac

Скачайте универсальный DMG, откройте его и перетащите **Phaint** на папку **Applications** («Программы»). Извлеките образ и запустите Phaint из «Программ». Один файл подходит для Mac с Apple Silicon и Intel под macOS 13 Ventura и новее. Можно рисовать мышью или трекпадом. Нажим пера проверен на Wacom CTL-672. [Скачать релиз](https://github.com/pozitron57/phaint/releases/latest)

При первом запуске выберите **Русский** или **English**. Чтобы сменить язык во всех окнах, откройте **Phaint → Настройки…** (**⌘,**), выберите язык и нажмите **Сохранить**.

У приложения локальная подпись ad-hoc, нотарификации Apple у этого выпуска нет. Если macOS заблокировала первый запуск и вы доверяете загруженной копии, один раз попробуйте открыть Phaint. Затем перейдите в **Системные настройки → Конфиденциальность и безопасность** и разрешите запуск Phaint. На управляемом Mac доступность этого действия зависит от администратора. [Инструкция Apple](https://support.apple.com/ru-ru/102445)

## Как нарисовать график на занятии

1. Нажмите **C**. Коснитесь холста в точке будущего наконечника вертикальной оси и проведите вниз и вправо до наконечника горизонтальной. Обе оси появятся за один жест.
2. Нажмите **S** и потяните в сторону для синусоиды или выберите **P** для параболы. У параболы первым движением соедините концы, оторвите перо и вторым движением задайте изгиб.
3. Нажмите **D**, чтобы подписать график от руки. **Q**, **W** и **E** выбирают синий, зелёный и красный цвет. **4** включает маркер. **Z** отменяет действие, **Y** его возвращает.
4. Для перемещения по холсту удерживайте **Пробел** и двигайте указатель. Щипок трекпада или прокрутка с **Ctrl** меняет масштаб. **0** сбрасывает масштаб и поворот.

| Клавиша | Что рисует |
| --- | --- |
| L / A / Shift+A | Прямая, стрелка или двусторонняя стрелка. Во время движения Shift задаёт угол с шагом 15°. |
| O | Окружность от центра. Удерживайте Shift при рисовании эллипса. |
| H / Shift+H | Ветвь гиперболы или адиабата. Направление движения выбирает четверть. |
| 1 / 2 / 3 | Сплошная линия, штрихи или точки. F1 и F2 меняют толщину. |
| ⌘⇧E | Ластик. Отмена восстанавливает стёртое за один жест. |

## Работа с объектами

**Tab** перебирает цвета по порядку. В **⌘, → Цвета Tab** можно изменить оттенок, добавить или удалить цвет и переставить его стрелками. Нажмите **Сохранить**, чтобы применить список. **Shift+Tab** открывает полную палитру.

**X** выбирает объект. Обведите рамкой несколько объектов или меняйте состав выделения с ⌘ и щелчком. Тяните внутри рамки для переноса, за угол — для изменения размера или отражения, за круглую ручку — для поворота. Стрелки клавиатуры сдвигают выделение, а при пустом выделении прокручивают холст. Цветные ручки меняют параметры самой фигуры, например период синусоиды. **B** открывает настройки текущего инструмента или выделения.

**G** показывает или скрывает сетку. **Shift+G** открывает шаг сетки, привязку к ней и привязку картинок друг к другу. Скрытая сетка тоже может притягивать фигуры. Option (Alt) временно обращает привязку при рисовании. **V** вставляет картинку из буфера под указателем, **Option+V** ставит её точно в указанную точку. Для копирования и вставки выделенных объектов нажмите **⌘C / ⌘V**.

**⌘⇧V** освобождает место между записями. Коснитесь холста и потяните по вертикали, чтобы сдвинуть объекты, лежащие целиком ниже точки касания. **N** или **Shift+B** скрывает и показывает панель. **⌘,** открывает настройки всех клавиш с поиском. Выберите назначение, нажмите своё сочетание и кнопку **Сохранить**. Физические клавиши работают одинаково при русской и английской раскладке.

## Сохранение и экспорт

- **⌘O** открывает SVG, картинку или PDF. Во внешних SVG можно выбирать отдельные контуры. Некоторые элементы, включая фильтры и сложные группы, сохраняются целиком в векторном виде. Перед открытием SVG встройте в него внешние картинки.
- **⌘S** сохраняет редактируемый SVG с нажимом пера и параметрами фигур. При выделении эта команда записывает выбранные объекты в отдельный SVG. Чтобы сохранить весь холст, сначала снимите выделение клавишей **Esc**.
- **⌘E** экспортирует выделение или весь рисунок в SVG, PDF, PNG или JPG. В диалоге можно выбрать сетку и сжатие. Для PDF с пометками режим исходных страниц сохраняет разбиение на страницы и их векторное содержимое.
- **⌘T** открывает отдельный холст. У каждого окна своя история отмены и резервная копия. После сбоя запустите Phaint и подтвердите восстановление.

## Сборка из исходников

На macOS установите Node.js 22.18 или новее с npm и Xcode Command Line Tools. Из корня репозитория установите зависимости и запустите Phaint.

```sh
npm ci
npm start
```

`npm run dmg` создаёт универсальный DMG в `release/<версия>/`. Для проверки выполните `npm run typecheck`, `npm test` и `npm run e2e`.

Phaint распространяется под GNU Affero General Public License версии 3 или любой последующей. У каждого релиза есть ссылка на его исходный код. Лицензии библиотек находятся в `Contents/Resources/Licenses` внутри приложения. Исходники включённой MuPDF 1.28.6 содержат сценарии сборки WebAssembly в `platform/wasm`. ## Как добавить язык

1. Из корня репозитория скопируйте `src/locales/en.json` в тот же каталог под кодом языка, например `fr.json` или `pt-BR.json`. В поле `name` укажите самоназвание языка, например `Français`. При сборке Phaint сама добавит язык в диалог первого запуска и в настройки.
2. Переведите каждое значение в `messages`, сохраняя ключи. Например, для `file.saved` подойдёт `«{name}» enregistré`. Сохраните имена подстановок и фигурные скобки. Слова и подстановки можно переставлять.
3. Выполните `npm run check:locales`. Проверка укажет язык и ключ для пропущенной, пустой или лишней строки, а также для ошибки в подстановках. Чтобы найти текст, который мог остаться на английском, выполните команду ниже, заменив `fr` своим кодом. Просмотрите совпадения вручную — названия форматов и сочетания клавиш могут совпадать.

   ```sh
   node -e 'const en = require("./src/locales/en.json").messages;
   for (const [key, text] of Object.entries(require("./src/locales/fr.json").messages))
     if (text === en[key]) console.log(key, text)'
   ```

4. Запустите `npm start`, выберите язык в **⌘,** и сохраните рисунок. Проверьте формулировки в меню и имя файла в уведомлении. Команда `npm run keyboard` пересоберёт клавиатурные шпаргалки для визуальной проверки.
