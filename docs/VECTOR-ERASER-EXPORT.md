# Векторное стирание и усиленное сжатие — 0.6.27

Проверка 18 ноября 2026. Оригиналы не менялись. Все входные копии, сценарии,
выходы, размеры, хеши и снимки: `release/0.6.27/comparison/`.

## Исходники и условия

- Текущий `phys.pro/1379.svg`: 88 216 байт, без metadata, после внешней минификации;
  один SVG-объект с прежней маской ластика. Именно этот файл проверен отдельно.
- Рабочая копия 1379 из предыдущего замера: 463 505 байт, 166 штрихов + внешний путь
  с 239 следами ластика. Нужна для воспроизводимого сравнения аппроксимации пера.
- Предложенный пользователем `1388p.svg`: 923 236 байт, родной Phaint, 416 штрихов,
  масок нет. Основная проверка нового режима сжатия.

Сравнение кривых: координаты 2 знака, SVG без metadata и без SVGO, вставленные картинки
в исходном качестве. Сетка включена: pattern в SVG, пути в PDF. Допуск 0 — контрольный
вариант без аппроксимации, с тем же округлением координат. Во всех вариантах одна и та
же рамка. Для текущего 1379 без metadata сравнивается только замена маски, без добавления
сетки и без повторной аппроксимации чужих контуров. Размеры ниже в байтах.

Рабочий SVG продолжает хранить редактируемые маски. В PDF их граница строится через

подбор кривых 0,006 px до местных ограничений и округления). Нерегулярные/полутоновые
внешние маски оставляются как есть; превращение прозрачности в жёсткую обрезку изменило бы рисунок.

## Более сильное сжатие

«Погрешность контура» задаёт общий предел отклонения аппроксимации Безье от готовой
границы штриха. Отдельно действует местная защита: обычно не больше 10% толщины,
дополнительный предел по размеру петли и по расстоянию до соседней границы.
Поэтому допуск 3 не означает, что тонкую линию разрешено сдвинуть на 3 px.

Эксперимент 3 → 6 → 12 с прежней защитой уменьшил данные путей 1379 только на 2 байта,
1388 — на 96 байт. Расширять шкалу ради этого не стали.

Новая галочка «Сильнее сжимать тонкие линии» допускает до 20% местной толщины вместо
10%. Общая погрешность и защита просветов продолжают действовать. Галочка по умолчанию
снята; при допуске 0 недоступна; выбор хранится отдельно для SVG/PDF. Данные нажима,
рабочий SVG и письмо ручкой не меняются.

в скрытом проверочном окне; тяжёлая геометрия выполняется в Worker.

## Внешний вид

PDF проверены при 200%, увеличенные фрагменты текста, окончаний, стрелок и маркеров —
визуально. У усиления слегка меняются края некоторых букв; это сжатие с потерями,
хотя при обычном размере разница малозаметна. Тонкие окончания, просветы и смысл чертежа
на проверенных рисунках сохранены. Универсальной гарантии незаметности для любого
почерка нет — поэтому режим отдельный и выключен по умолчанию.

Для 1388 по сравнению с допуском 0: среднее отклонение RGB при допуске 3 — 0,241/255,
с усилением — 0,372/255; доля пикселей с отличием >32 — 0,407% и 0,573%.
Для SVG 1379 в Chromium: 0,251 и 0,440/255, соответственно 0,546% и 0,808% пикселей.
Числа характеризуют весь лист с белым фоном, поэтому не заменяют просмотра краёв.

В `images/` находятся целые листы и тройные сравнения: исходный контур / допуск 3 /
допуск 3 с усилением. `strong.json`, `1388.json`, `current.json` содержат точные размеры;
`*-pixels.json` — замеры изображений; `manifest.json` — хеши входов и выходов.

Дополнительно SVG 1388 проверены в Chromium при 200%: среднее отличие от допуска 0 — 0.236/255 (1388-3-normal), 0.368/255 (1388-3-strong). Снимки `1388-*-svg.png`, числа — `svg1388.json`.
