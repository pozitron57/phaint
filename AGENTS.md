# Phaint

Векторная рисовалка для онлайн-уроков на планшете Wacom. TypeScript + Electron, только macOS 13 и новее (Apple Silicon и Intel).

- ТЗ, хоткеи, принятые решения и этапы: [docs/SPEC.md](docs/SPEC.md). Перед новой функцией сверяйтесь с ним.
- Статус v0.6: перо, прямая/стрелка, координаты, окружность/эллипс, синусоида, парабола, гипербола/адиабата, штрихи/точки,
  маркер, ластик, SVG, PDF/PNG/JPG, буфер объектов, восстановление. X: временная группа, рамка, перенос, размер,
  отражение, поворот и параметры фигур. Cmd+Shift+V: вертикальное раздвижение.
  Внешние SVG разбираются на контуры и отдельные SVG-фрагменты.
  Все клавиши, включая удерживаемые модификаторы жестов, настраиваются через Cmd+,.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm start` | сборка и запуск в окне разработки |
| `npm test` | тесты ядра (`test/*.test.ts`, Node исполняет `.ts` напрямую) |
| `npm run typecheck` | проверка типов |
| `npm run smoke` | самопроверка в Electron без показа окна, снимок в `dist/e2e/smoke.png` |
| `npm run e2e` | инструменты, группы, SVG, ввод, сбой/восстановление и закрытие; снимки в `dist/e2e/` |
| `npm run load` | нагрузка 50 000 штрихов в настоящем окне (появляется на несколько секунд) |
| `npm run load:files` | сохранение SVG с 50 000 штрихов и замер плавности |
| `npm run dmg` | универсальные Phaint.app и DMG для Apple Silicon и Intel в `release/<версия>/` |
| `npm run icon` | `assets/icon.svg` → `assets/icon.icns` |
| `npm run package` | `release/Phaint-darwin-arm64/Phaint.app`; `-- --out=release/0.6` — отдельная сборка рядом с открытой прежней версией |

## Как устроено и почему

- **Окна:** Dock/повторный запуск всегда возвращает последнее активное окно, в том числе скрытое
  или свёрнутое; новые окна не создаёт. Cmd+T создаёт независимый холст со сдвигом на 24 пункта
  от активного окна; `window-position.ts` удерживает каскад в рабочей области его экрана.
  Cmd+Tab — только переключение, порядок событий активации macOS не влияет на число окон.
  Один главный процесс, отдельные рендереры и история. Первичная
  активация macOS не создаёт лишнее окно. `documentWindows` исключает служебные окна PDF.
  Меню берёт назначения активного окна. `WindowSettings` пишет разницу с последним снимком
  каждого окна; открытые окна сохраняют свои настройки, новые читают последние пресеты.
  Cmd+Q закрывает окна последовательно через `files.close`; `closeReady(false)` останавливает
  выход при отмене или ошибке. У каждого окна свой recovery-файл; после сбоя открываются все
  найденные копии, включая прежний `recovery.json`. Новый холст не читает чужую копию.
- **Полный экран:** отдельный Space macOS. После `enter-full-screen` нативный модуль
  снимает только `NSWindowStyleMaskTitled`, чтобы заголовок не выезжал при наведении.
  После `leave-full-screen` обычная рамка восстанавливается. Не возвращайте Titled
  до конца анимации выхода: это конфликтует с переносом панели заголовка в AppKit.
- **Объекты неизменяемы.** Правка — новый объект; история хранит пары `{added, removed}`.
  Точки штриха — `Float32Array` троек `x, y, w` в локальных координатах (`ox, oy` — начало),
  `w` — толщина, уже посчитанная из нажатия. Кэш контура (`Path2D`) привязан к объекту через `WeakMap`.
- **Бюджет истории:** `history-memory.ts` считает общие объекты/строки/буферы один раз,
  предел 128 МиБ на окно относится к данным JS, без кэшей Chromium. Старые шаги удаляются
  целиком; текущий жест временно сохраняется сверх бюджета для Esc и прежнего Redo.
  После `endGroup` слишком большой одиночный шаг удаляется с уведомлением. F12 показывает бюджет.
- **Отмена файлов:** `files/processing.ts` даёт кнопку после 400 мс и отдельный Worker
  операции. `ui.escape` работает и при заблокированном вводе. AbortSignal проходит через
  SVG/растры/PDF.js; PDF IPC отменяется по идентификатору в пределах окна. Перед атомарной
  заменой операция `seal()` запрещает отмену. Временные файлы/окна/потоки очищаются,
  фоновые копии и буфер не прерываются. Отложенное восстановление Electron сохраняет старый
  recovery-файл, переключая окно на новый путь (`deferRecovery`).
- **Вид:** `устройство = D · мир + (tx, ty)`, сдвиг целый в пикселях устройства — плитки копируются 1:1.
- **Плитки** 512 px рисуются на процессоре (`willReadFrequently`) и после каждых 16 объектов
  принудительно дорисовываются (`flush` в `tiles.ts`). Причина: Chromium откладывает отрисовку,
  `fill()` только записывает команду, и без этого бюджет времени кадра ничего не измеряет —
  были задержки до 0,4 с. Не убирайте `flush` и не переводите плитки на видеокарту без замера `npm run load`.
- **Уровни плиток:** при смене масштаба или поворота заводится новый уровень, прежний показывается
  растянутым. Во время щипка уровень терпит расхождение масштаба до 1,5 раза (`STRETCH`).
- **Бюджет кадра на плитки:** 1,5 мс пока перо рисует, 7 мс пока вид движется, 11 мс в покое (`renderer.ts`).
- **Маски:** `DocChange.damage` ограничивает область перерисовки, если геометрия не менялась.
  Готовая плитка обновляется маленьким прямоугольником со всеми слоями. Очень плотная область
  возвращается в обычную очередь по бюджету. `inheritImage` сохраняет и неизменившийся `Path2D`.
- **Текущий штрих** рисуется на отдельном холсте `live` каждый кадр; при отрыве пера дорисовывается
  поверх готовых плиток без их перерисовки (`DocChange.top`).
  Для всех параметрических фигур `TileCache` сохраняет нижние и верхние слои. Выбор одной фигуры в X
  заранее готовит видимые плитки; движение не сбрасывает незавершённую очередь соседей.
  Верхние обычные объекты объединяются в прозрачный холст. При multiply два непрозрачных
  пробных фона дают коэффициенты `A·фон+B` для всего верхнего плана (`tile-overlay.ts`),
  независимо от числа маркеров. Во время жеста возможна разница округления RGB; после
  отрыва обычная отрисовка возвращает точные пиксели, сохраняя кэш следующего жеста.
  `busy` включён также при переносе/преобразовании одной фигуры и у её ручек/Безье X.
  Другие изменения освобождают обе части кэша,
  смена сетки обновляет его под маркером. Порядок объектов, маски и экспорт не меняются.
- **Контур штриха** (`outline.ts`): осевая линия уплотняется на поворотах сплайном Катмулла — Рома,
  по ней строится лента с круглыми концами; в острых углах лента рвётся, на тугих завитках добавляются диски.
- **Касание:** `StrokeBuilder` отличает точку по максимальному удалению от начала, а не
  длине дрожащей траектории. Допуск — до 4 экранных px, меньше у тонкой кисти. Готовая
  точка не тоньше базовой кисти; пиковый сырой нажим может увеличить её без taper/speed.
  Предпросмотр и геометрия обычного штриха не меняются.
- **Фигуры:** `StrokeObj.shape` хранит параметры и матрицу фигуры, `pts` — готовую осевую линию.
  `shapes.ts` даёт общие контуры штрихов/головок для Canvas и SVG. Рамка включает наконечники.
  `headRound` — степень скругления треугольника; отсутствие параметра сохраняет прежний контур.
  `headGridStep` фиксирует шаг при создании наконечника. Полный размер достигается на двух клетках
  вдоль оси стрелки с учётом места для стержня. Старые SVG используют прежний расчёт.
  У прямой стрелки `segmentOutline` даёт ровные боковые стороны и плоский торец у головки.
  Гипербола — ветвь 1/x на [1/4,4].
  Адиабата — x^(-γ) на том же диапазоне, нормированная к квадратной рамке; γ меняет
  изгиб без сдвига концов. `shape.gamma` хранит точное значение (по умолчанию 5/3),
  `settings.hyperbola.gamma` — значение для новых адиабат. У пары одна толщина.
  Обе кривые отражаются по знакам движения через `frame.a/d`, сохраняя четверть в SVG.
  `controls` у прямой/стрелки — 1–2 точки Безье в системе `frame`. Кривая уплотняется
  адаптивно. Открытые головки следуют аналитическим касательным, заполненные опираются
  основанием на саму дугу (`headArc`). `strokeOutline` строит тот же стержень, что у линии,
  и срезает торец в плоскости основания. В X A перебирает конец, начало, оба конца и линию.
  Shift+A идёт обратно, L сразу убирает головки, Ctrl+A переносит одиночную.
  В SVG `headAtStart` хранит сторону. `otherHead` сохраняет оформление другого режима,
  `savedHeadStyle` и `both` восстанавливают головки после временного перехода в линию.
  В X доступны оба конца прямой или стрелки и основания головок из `arrowHeads`.
  `snapSegment` привязывает вершину в координатах холста. Alt освобождает её, Shift задаёт
  угол и шаг длины, как при рисовании. У начала переносится `frame`, дальний конец
  и контрольные точки сохраняют положение на холсте.
  `coordinates` — один объект с толщиной и параметрами головок стрелки. `pts` хранит ноль и два
  наконечника; `coordinateAxes` даёт два отдельных пути для контура и ластика, без диагонали.
  `coordinateFrame` сохраняет прямой угол при непропорциональном растяжении. X даёт
  две ручки длины и центр вращения в нуле. Касание/отрыв задают наконечники.
  `snapToGrid` — общая настройка (по умолчанию true), Alt временно обращает её.
  Начало всех фигур, первый наконечник координат и центр эллипса фиксируются при касании.
  Синусоида/парабола/гипербола/адиабата привязывают только начало; остальная геометрия свободная,
  отсчитывается от привязанной точки. Поздний Alt её не двигает.
  Ctrl+касание в L/A правит последнюю фигуру, в X — одну выбранную, включая старые SVG Phaint.
  Один жест — одна отмена. X двигает готовые ручки без модификаторов; Cmd меняет состав выделения.
  Правый щелчок/вторичный тап трекпада по ручке Безье удаляет одну точку в L/A или X;
  последняя точка возвращает прямую. `contextmenu` обрабатывается один раз, Ctrl-click
  macOS сохраняет постановку/движение точки. Удаление — отдельный Undo, концы неизменны.
  `Tool.settingsChanged`/`modifiersChanged` обновляют незавершённую фигуру по клавишам.
  Ручка амплитуды синусоиды при переходе через ось отражает `frame.c/d`; амплитуда
  неотрицательна, ноль не вырождает матрицу. Начальные 3/8 клеток амплитуды/периода
  применяются к прежнему профилю один раз при переходе настроек на версию 10.
- **X:** список неизменяемых объектов, одна группа истории на жест. Собственные точки
  преобразуются с сохранением толщины по настройке. Маркер, SVG, PNG и отдельные внешние
  контуры используют полную матрицу. Пропорциональный размер за угол ведёт экранная X;
  Y задаёт только отражение, Shift разрешает независимые оси. Центр поворота — временное
  свойство выделения с прилипанием к рамке (Alt — свободно). Cmd+касание из любого инструмента рисования переключает на X;
  отпускание Cmd сохраняет выбор, повторное X возвращает прежний инструмент.
  Ctrl+F/B — на передний/задний план, Ctrl+Shift+F/B — на один шаг; внутренний порядок
  группы сохраняется. `order.ts` переставляет z, общий Undo включает затронутых соседей;
  одинаковые z фрагментов ластика упорядочиваются при первой перестановке.
  Допуск клика — 10 экранных px; `ObjectPicker` выбирает ближайший видимый контур,
  при равном расстоянии — верхний слой. Учитываются толщина, штрихи, матрицы и маски;
  сложные SVG/обводки/обрезка проверяются маленьким растром с шагом 1/2 экранного px.
  Ручки и перенос внутри рамки текущей группы сохраняют приоритет.
  Чистый перенос в `transformObject` сохраняет локальные
  точки/матрицы/маски и позволяет `inheritImage` переиспользовать готовый контур.
- **Раздвижение:** `SpaceTool` (Cmd+Shift+V) фиксирует мировую Y и объекты с `bbox.minY`
  ниже касания; пересекающие линию, фон и PDF-подложки неподвижны. Свободный перенос по Y
  вверх/вниз, без сетки. Предпросмотр меняет документ без пересчёта памяти истории;
  один шаг записывается при отрыве, Esc и возврат к началу сохраняют прежний Redo.
  `Tool.scrollDuringDrag` разрешает колесо/стрелки; `viewChanged` пересчитывает перенос
  от последней экранной точки сразу после изменения вида, без ожидания движения пера.
  Щипок/масштаб/поворот при контакте заблокированы, Пробел завершает жест.
- **Выделение и файлы:** перенос в X начинается после 5 экранных пикселей. Рамка выбора
  не сохраняется. Cmd+S с выделением пишет целые объекты в отдельный SVG; закрытие/замена
  документа всегда сохраняет полный рисунок. Старый `Obj.clip` продолжает поддерживаться:
  выпуклая локальная обрезка следует за преобразованиями, применяется после масок и при стирании.
- **Буфер:** `files/object-clipboard.ts` сериализует только выбранные объекты в Worker;
  `electron/clipboard.ts` пишет стандартный SVG и текст. Вставка назначает новые id/z,
  размещает верхний левый угол группы под курсором и записывает один шаг истории.
  `clipboardCopy` сообщает о подготовке SVG: вставка из соседнего окна дожидается копирования;
  последнее Cmd+C имеет приоритет независимо от времени подготовки. Закрытие/сбой источника
  снимает ожидание. Системный буфер общий для всех окон.
  Cmd+C/V в текстовых полях передаются обычным действиям WebContents/AppKit. V вставляет
  картинку с привязкой, Alt+V — точно под курсором. `ImageSnap` привязывает края соседних
  растровых картинок по X/Y независимо. По свободной оси левый верхний угол прилипает к сетке. В X привязка
  работает также для общей рамки нескольких картинок и рисует временные направляющие.
  При изменении размера поправка сохраняет неподвижный угол или центр и пропорции, Shift ведёт оси
  независимо. Вертикаль левого поля ищется среди остальных картинок один раз на жест, без ограничения
  по высоте. Совпадение левых краёв обозначается пунктиром. Для других объектов и смешанных групп
  X фиксирует ближайшую к касанию опору и ставит её на сетку. `gesture.grid` временно отключает
  привязки при переносе и изменении размера. `snapToImages` — флажок Shift+G.
- **Распознавание:** Ctrl+C — текст одной выбранной растровой картинки через Apple Vision,
  локально, без LaTeX. `files/image-text.ts` ведёт отменяемую операцию без блокировки холста;
  `native/text_recognition.m` декодирует исходные пиксели/EXIF и прежнюю обрезку, распознаёт
  русский/английский вне главного потока через N-API async work. Документ/история не меняются.
  Перед записью в буфер `electron/problem-text.ts` убирает начальный номер задачи с уточнением
  и стрелками навигации.
  `electron/clipboard.ts` проверяет общий номер копирования и `NSPasteboard.changeCount`:
  поздний OCR не затирает новое копирование, в том числе из другой программы. Только текст
  записывается через AppKit. Esc/кнопка, замена документа, закрытие/сбой окна отменяют запрос.
- **Экспорт:** Cmd+E — целое выделение или весь рисунок. `files/export.ts` — диалог и
  PNG/JPG на белом фоне, максимум 24 Мп/12 000 px; `electron/pdf.ts` — одна векторная
  страница через изолированное окно без JS/сети. Фоновая операция `visual` отдаёт SVG
  без metadata и хеша. Файлы пишутся атомарно, признак изменений документа не сбрасывается.
  `electron/export-history.ts` хранит последнее назначение Cmd+E по пути исходника отдельно
  для рисунка и выделения. Сессия помнит экспорт безымянного холста до первого сохранения.
  `files/export-options.ts` — отдельные настройки SVG/PDF/PNG/JPG в `Settings.export`;
  общий `includeGrid` управляет сеткой только в экспортной копии. Флажок находится в Cmd+E,
  в панели сетки его нет. Скрытая сетка и режим исходных страниц PDF недоступны; выбор помнится.
  `chooseExport` получает размеры с сеткой и без неё, меняет пропорции PNG/JPG при выборе;
  сессия пересчитывает окончательную рамку. Отмена не меняет настройки или рабочий SVG.
  PNG/JPG задают ширину в пикселях, высота по пропорциям. `files/png-compression.ts`
  меняет степень zlib-сжатия PNG (0–9, по умолчанию 6) через fflate в Worker;
  декодированные пиксели, фильтры и цветовые профили неизменны, буферы передаются без копирования.
  SVG/PDF: один бегунок сжатия 0–20, равномерные целые ступени. `compression` в
  `VectorOptions` задаёт допуск/знаки/защиту толщины/качество картинок через `vectorOptions`;
  старые поля остаются для совместимости. 19 — прежний максимум, 20 немного сильнее.
  `contour-export.ts` объединяет перекрытия (Clipper nonzero), `contour-fit.ts` подбирает
  Безье с проверкой целых дуг, `contour-limits.ts` защищает местную толщину и просветы.
  `contourDetailLoss` ослабляет защиту на верхних ступенях, максимум 1,1. Степень потерь
  берётся до деления допуска на масштаб матрицы. Исходные отсчёты не меняются.
  В диалоге кнопки SVG/PDF/PNG/JPG, без пресетов и отдельных геометрических настроек.
  Высота диалога постоянна по полному SVG-варианту; `.export-content` прокручивается
  внутри, `.export-actions` сохраняет положение нижних кнопок.
  Cmd+S выделения разрешает только SVG; `names.ts` даёт `file-part.svg` / `YYYY-MM-DD-part.svg`.
  Для этого экспорта SVGO не округляет и не упрощает геометрию повторно.
  `grid-svg.ts` оставляет pattern для SVG, явные пути для PDF: Chromium растеризует pattern.
  `eraser-clip.ts` в PDF объединяет следы ластика и вычитает их из рамки (Clipper nonzero),
  записывая векторный clipPath вместо mask. `svg-eraser.ts` распознаёт тот же ластик после
  SVGO без metadata; полутоновые/неизвестные маски остаются как есть. Всё в Worker,
  рабочие SVG/история не меняются; `vectorMasks` — внутренний флаг экспортной копии PDF.
  `pdf-worker.ts`/`pdf-optimize.ts` сжимают PDF через pdf-lib и убирают шум Float32-координат
  без изменения их значений; изображения не перекодируются.
  `export-images.ts` уменьшает вставленные картинки
  только в экспортной копии, последовательно в Worker. Прозрачность — PNG, чужой SVG неизменен.
  `DocumentData.exportOptions` существует только для операции, в metadata не записывается.
  `svg-export.ts` исключает metadata при флажке SVGO; `svg-optimize.ts` загружается лениво
  в Worker и выбирает меньший из обычного SVG и двух профилей SVGO (один сохраняет матрицы).
  `file-stats.ts` — размеры UTF-8 и результат обработки; `DocumentSession.lastWrite` для F12
  обновляется только после успешной записи. Поток SVG считает байты по готовым порциям.
  Cmd+S с выделением показывает настройки SVG; обычное сохранение всегда максимально точное.
  `names.ts` задаёт рабочие имена и экспорт: `1889p.svg` → `1889.svg` в той же папке.
  Для нового рисунка имя — текущая местная дата `YYYY-MM-DD` и расширение формата;
  существующие имена сохраняются. Дата вычисляется при открытии диалога, без UTC-сдвига.
  При сохранении сетки `exportSize` округляет границы наружу до её узлов; `gridSvg`
  добавляет внешнюю рамку. Новые документы сохраняют сетку по умолчанию.
- **PDF-подложки:** `ImageObj.pdfPage`/`SvgObj.pdfPage` закреплены; X и ластик их не изменяют.
  `isPdfPage`/`isLocked` общие для обоих видов. Исходный PDF хранится один раз в
  `DocumentData.pdf`. `pdf-svg.ts` преобразует подложки в векторные SVG через MuPDF
  в Worker при сохранении/экспорте (metadata v6). Шрифты — контуры с defs/use, id страниц
  независимы. Старые PNG-подложки v5 преобразуются при следующей записи; готовые SVG
  переиспользуются. `compactPdfSvg` меняет только запись путей с высокой точностью,
  до вычисления metadata, не затрагивая собственные штрихи. MuPDF/WASM и SVGO загружаются
  лениво; лицензия MuPDF включена в сборку. Видимые SVG не дублируются в metadata.
  `pdf-render.ts` и PDF.js загружаются по запросу. Все миниатюры до 16 Мп; `PdfView`
  кэширует максимум три видимые страницы по 8 Мп отдельно от объектов/истории и обновляет
  плитки после смены чёткости. При открытии SVG `prepareObjects` также ограничивает
  миниатюры PDF 16 Мп суммарно/1 Мп на страницу и хранит ImageBitmap. Рендер откладывается
  при письме и после движения вида.
  Экспорт PDF собирает оригинальные потоки и прозрачные векторные пометки в Worker
  (`pdf-compose.ts`): исходные страницы одним файлом либо длинный лист. Не пропускайте
  оригинальные потоки через оптимизатор пометок. Размер/поворот/CropBox сохраняются.
  Каждый маркер печатается отдельным слоем с PDF Multiply; обычные пометки между ними
  объединяются. Слои одной страницы печатаются одним запуском, порядок наложения сохраняется.
- **Точки:** `DashStyle.dots` и шаг `gap` задают отдельные круги вдоль осевой линии.
  `InkSettings.dotted/dotSpacing` сохраняют пресет отдельно от штрихов. Metadata v4 для
  точек, v3 для clip; более старые Phaint читают такие файлы как видимый SVG.
- **Маркер:** один путь, одна заливка с opacity и multiply. В плитках с маркером подложка
  и сетка рисуются внутри плитки (иначе multiply не видит сетку); смена сетки обновляет их.
  У маркера на live — CSS multiply. Масштабирование и маски старых файлов не делят его на темнеющие фрагменты.
- **Вставка V:** NSImage даёт размеры в пунктах macOS, PNG сохраняет все пиксели. Размер объекта
  делится на `DocumentSession.baseScale`: 1 на новом холсте и при новом импорте внешнего SVG;
  прежние документы, растры и PDF сохраняют свой базовый масштаб.
- **Файлы:** SVG 1.1 с видимыми путями и точными данными пера в `metadata`. SHA-256 видимого
  SVG проверяется перед восстановлением штрихов. Внешние правки приоритетны: такой файл читается
  через `svg-parts.ts` как отдельные простые пути; `svg-fragment.ts` выделяет текст, use,
  градиенты, картинки и другие независимые элементы с их рамками и локальными ссылками.
  Прозрачность/обрезка сохраняют группу. Фильтры, смешивание, CSS и неподдерживаемая
  геометрия — единым SVG без растеризации. Внешние ресурсы должны быть встроены. `VectorObj` хранит d, оформление,
  локальную рамку и матрицу; контуры не превращаются в выдуманные осевые линии.
  Внешний SVG открывается по ширине окна с полями по 10% и отступом 30 px сверху.
  `svg-import.ts` масштабирует объекты матрицей, вид/baseScale остаются 1: сетка и кисти
  как на пустом холсте. Высота страницы не влияет на масштаб; свои SVG восстанавливают сохранённый вид.
  Вставка SVG из буфера вызывает тот же разбор с `fitToWidth:false`, сохраняя исходный размер.
- **SVG/PNG не дублируются в metadata:** там ссылка на видимый объект между маркерами комментариев;
  у отдельного контура — ссылка на path по id. Одинаковые матрицы соседних контуров объединяются.
  Длинная metadata сжимается deflate/base64, видимые пути остаются SVG.
  `loopsToSvg` выбирает короткие абсолютные/относительные Q/T без изменения точности.
  Маски с общей матрицей и радиусом записываются одним путём с отдельными капсулами.
  Координаты d не округляются; рамки импорта округляются наружу, чтобы не раздувать metadata.
  Маски SVG хранятся отдельно от источника; Canvas применяет их на отдельной плитке через destination-out.
  Изменённые объекты наследуют декодированную картинку через `inheritImage`.
- **Сохранение:** построение SVG/резервной копии в Worker, снимок передаётся по 256 объектов,
  файл записывается порциями по 128 К символов через временный файл + fsync + rename. Worker
  освобождается через 5 с простоя. Исходный файл не перезаписывается, если его меняла другая программа.
- **Сессия:** обычный запуск пустой. Резервная копия после 5 с тишины (до минуты при непрерывных
  изменениях, ждёт окончания текущего штриха), только при изменениях. Штатное закрытие спрашивает
  о сохранении; после сбоя предлагает восстановление. Тесты используют отдельные временные данные.
  Cmd+R открывает последний рабочий файл: `recent.json` хранит путь в главном процессе;
  `FileApi.recent/read/remember` передают только непрозрачные ссылки. Запоминание — после
  успешного открытия/полного сохранения, никогда после экспорта. Цель Cmd+R выбирается до
  подтверждения несохранённого рисунка, содержимое читается после возможного сохранения.
- **Ластик:** разрезает осевые линии с учётом толщины; фрагменты остаются обычными штрихами
  с прежним цветом, нажимом и z. Быстрый проход проверяется целиком между отсчётами. История
  объединяет контакт пера в один шаг; Esc откатывает текущий проход. Маркер удаляется целиком
  по контуру (`hit.ts`), заполненные головки — масками. Собственный контур имеет `native:true`.
  По отдельной кнопке «исходный SVG» под ластиком внешний вектор тоже стирается масками; PNG не затрагивается.
  След — 5 чисел в старых файлах либо 11 (капсула + обратная матрица в момент стирания).
- **Предсказание:** по умолчанию выключено; `prediction.ts` ограничивает дальность/время.
  Настоящие точки никогда не заменяются прогнозом. Pointer events запрашивают прогноз только
  у ручки с включённой настройкой; в покое нет кадров и постоянного Worker.
- **Завершение ввода:** pointerup, потеря захвата, pointercancel и потеря фокуса сохраняют уже
  полученные точки. Отбрасывание — только по Esc. Движение без нажатой кнопки также завершает штрих.
- **Нажим Wacom:** после запуска Screenshot Chromium может пометить перо как `mouse`,
  сохранив настоящий `PointerEvent.pressure`. `pointer.ts` использует нажим независимо
  от `pointerType`, включая промежуточные отсчёты и последнюю точку перед отрывом.
  У обычной мыши сам PointerEvent даёт 0,5. Не заменяйте нажим по имени устройства.
- **Цвет и вид линии:** `stylePerTool` переключается по F5 или флажком в B. По умолчанию
  все инструменты используют `sharedStyle`. При включённой привязке каждый инструмент
  хранит свой стиль. Явный выбор цвета или штриха обновляет также соответствующую часть
  общего стиля. Q/W/E выбирают синий/красный/зелёный, Tab перебирает цвета. Толщина берётся из настроек инструмента. Shift+G открывает панель сетки.
- **Схема модификаторов:** Shift — геометрия, Alt — привязки, Cmd — выбор, Ctrl — Безье/размер от центра.
  Первый Cmd-жест из рисования выбирает и может переносить, следующие в X меняют состав.
  Ручки X имеют приоритет перед Безье; Ctrl+угол — размер от центра.
  1/2/3 выбирают сплошную/штрихи/точки. `style.dash` — настраиваемая команда прямого перебора,
  Shift+2 перебирает обратно, 5 переключает точки.
  При рисовании A/Shift+A выбирают один/два наконечника стрелки. Повтор того же режима
  возвращает прежний инструмент. Курсор и панель учитывают `arrow.both`. `arrow.doubleHead` задаёт
  оформление двусторонней стрелки, `arrow` — одиночной, `coordinates` — осей координат.
  Панель B сохраняет эти настройки. Shift/Ctrl+F1/F2 меняют головки только у выбранной
  или только что нарисованной фигуры через историю документа.
  Кнопка прямой/стрелки помнит последний инструмент и переключает их повторным щелчком.
  У координат отдельная кнопка C.
  Явные пользовательские назначения при обновлении приоритетнее новых стандартных.
- **Курсор:** системное изображение цвета активной кисти; светлые оттенки получают
  нейтральную кайму. Ободок — сплошной, ровно четыре штриха или точки диаметром 2,4 px.
  У L диагональ проходит через центр с выступами по 3 px, у A выступ с головкой — 5 px.
  У Shift+A две головки и симметричные выступы по 5 px.
  У координат два отрезка из центра вверх/вправо с выступами по 3 px, без наконечников.
  `ui/cursor.ts` кэширует до 256 сочетаний диаметра/DPR/цвета/ободка/метки, без кадров холста.
- **Хоткеи** привязаны к `KeyboardEvent.code` и не зависят от раскладки.
  `actions-list.ts` — команды; `core/shortcut-info.ts` — описания, категории и жесты.
  `input.held(id,sample)` сопоставляет модификаторы: не проверяйте Ctrl/Alt напрямую в инструментах.
  `ui/shortcuts.ts` редактирует черновик `Settings.keys`; запись на диск предшествует применению.
  Поиск «+» сопоставляет клавишу цифрового плюса и Shift с Equal в назначениях черновика.
  Конфликты проверяются с учётом инструмента/жеста, снятое назначение не имеет запасной клавиши.
  `view.left/right/up/down` с выделением сдвигают объекты на ⅕ клетки, иначе прокручивают
  холст. `gesture.nudgeFine/Medium/Fast`: Alt — 1 экранный px, Ctrl — ½ клетки,
  Cmd/Shift — 2 клетки. При сочетании Alt приоритетнее Cmd/Shift, они приоритетнее Ctrl; направление
  экранное, расстояния в клетках не зависят от зума. `ActionDef.run` получает клавишу для объединения
  повторов; `SelectTool.nudge` сохраняет точки/контуры, переносит также ручной центр вращения.
  MenuItem Electron неизменяем: меню пересобирается при применении клавиш. В фокусе WebContents
  нативные ускорители отключены: их обрабатывает рендерер, включая запись Cmd+Q без выхода.
  Cmd+A из меню macOS передаётся через `platform.onSelectAll`; текстовые поля сохраняют
  своё выделение текста, на холсте выбираются все объекты, кроме фоновой подложки.
- **Первый Cmd+O:** `native.prepareFileDialogs` создаёт и закрывает невидимый NSOpenPanel
  во время загрузки рендерера, до показа главного окна. Это разовая подготовка без таймера;
  автоматические сценарии с подменёнными файловыми диалогами её пропускают.

## Правила

- После проверок самостоятельно делать коммит с кратким описанием изменений по задаче.
  Сборки, зависимости и результаты проверок исключены через `.gitignore`.
- После изменений приложения собирать новую версию. Пользователь заранее разрешает
  устанавливать каждую проверенную сборку без отдельного подтверждения, если Phaint полностью закрыта.
  Для установки обновлять приложение по постоянному пути `release/Phaint-darwin-arm64/Phaint.app`,
  на который указывает значок в Dock macOS.
  Проверять отсутствие работающего процесса перед заменой, сохранять прежнюю версию
  в её папке `release/<версия>/`, проверять подпись и запуск после установки.
  Пользователь должен получать обновление обычным запуском из Dock. Если Phaint работает,
  подготовить отдельную сборку и сообщить об отложенной установке; не закрывать приложение
  и не подменять его файлы без явной просьбы пользователя.
- Интерфейс, комментарии и документация — на русском, идентификаторы — на английском.
- Документация краткая: этот файл как карта плюс шапка в каждом модуле. Меняете устройство — обновите.
- Только стираемый синтаксис TypeScript (без `enum`, без свойств-параметров конструктора): тесты запускает Node.
- Рендерер должен работать и в обычном браузере: всё, что зависит от Electron, — через `platform.ts`.
- Локальный сервер для проверки — только порт 4847 (`.claude/launch.json`), после проверки гасить.
- Проверяйте глазами: сценарий для `--run` плюс `test.shot()`; снимки смотрите как картинки.
  Настоящее перо эмулируется событиями `PointerEvent` с `pressure` (`test.pen`).
- После правок: `npm run typecheck && npm test && npm run e2e`; если трогали отрисовку — ещё `npm run load`.
